BLE GroupConnect Privacy Policy

Effective Date: July 29, 2026

Preface

BLE GroupConnect is an offline local Bluetooth debugging tool built for embedded developers and hardware test engineers. It supports multi-device concurrent BLE connections, classic Bluetooth SPP, data transmission, GATT debugging, automated scripts, batch OTA/DFU hardware firmware upgrade, log export and other features. All operations and data storage of this app are processed locally on your device only; no user data, Bluetooth data or logs will be uploaded to the internet. This policy fully explains our rules for data processing, permission usage, third-party services and local data management.

1. Information Collection & Storage Rules

This app does not collect, upload, or share any personal information, Bluetooth communication data, debug logs or device lists.

All data generated during app operation is persistently stored locally on your phone only, including: favorite Bluetooth devices & connection history, multi-device workspace configurations, send/receive logs, Hex/ASCII quick commands, automated scripts, OTA upgrade scripts, custom GATT templates, local DFU firmware records, audio EQ configurations, etc.

You may clean all local cached data by category at any time via "Mine - Local Data Management" inside the app. All local files will be automatically deleted by the system once you uninstall the app, with no residual data left.

2. Required Permissions & Purposes

All permissions are only required to implement core Bluetooth debugging functions, and will never be used for irrelevant purposes such as information collection, location tracking or ad delivery:

  • Bluetooth Permission: Scan, discover and connect BLE hardware devices, read/write characteristics, subscribe to Notify data, send and receive debug messages in real time; support persistent background BLE connections.
  • Location Permission: Mandatory for Bluetooth scanning on Android 11 and earlier systems. This app will not read, record or upload any location data; location access is only to meet system prerequisites for BLE scanning.
  • Storage / Photo Library Permission: Export debug logs in TXT/CSV format, select local DFU/OTA firmware packages.
  • Notification Permission: Push progress and completion reminders for batch OTA upgrades and background automated script tasks.

3. Privacy Statement for OTA / DFU Firmware Upgrade

Important Statement: OTA and DFU firmware upgrade functions are solely for updating external BLE IoT hardware firmware. They cannot and will not be used to upgrade this app itself. There is no built-in self-update logic, app package download or external installation functionality within the app.

Firmware files are manually selected by users from local storage. The entire upgrade process transmits data only over the local Bluetooth link. Firmware packages and upgrade logs will never be uploaded to any server or third-party platform. Nordic DFU, custom BLE OTA and batch upgrade workflows run fully offline.

4. Automated Scripts, Batch Debugging & Log Export

All messages and records generated by automated scripts, multi-device concurrent debugging, cyclic transmission and log filtering are stored locally only. Free version has daily usage limits: 30 single-line transmissions, 10 script executions, 3 OTA script runs and 1 log export per day. Usage counters are stored locally and will not be synced to cloud servers.

5. One-Time Purchase Pro Version In-App Purchase

The app offers a one-time permanent unlock IAP for the Pro version, which removes all daily usage limits and unlocks all advanced debugging features.

  • Payment, order verification and purchase validation are fully handled by Apple App Store / Google Play official store;
  • This app cannot access, store or upload your payment accounts, order records, bank card information or other payment privacy data;
  • The "Restore Purchases" function inside the app only interacts with official store servers for order validation, with no third-party data forwarding.

6. Third-Party SDKs & Network Activities

This app is a fully offline tool with no persistent network requests. It does not integrate ad SDKs, user behavior analytics, event tracking, cloud synchronization or push statistics third-party components:

  • The built-in Bluetooth communication library only parses BLE protocols locally with no logic to send data externally;
  • The only temporary network call is for order validation during Restore Purchases; no other internet requests are made;
  • No local user data will be collected, shared or sold to any third-party company.

7. Children’s Privacy Protection

This app is a professional debugging tool targeted at hardware engineers and is not intended for users under the age of 13. We will not intentionally collect any personal information from minors. If guardians discover unauthorized use by children, please contact us for inquiries.

8. Data Retention & Deletion Mechanism

All local debug data (device lists, scripts, logs, firmware records, EQ configurations) are saved on your device until you take one of the following actions:

  1. Manually delete logs, scripts and device records by category via Local Data Management page;
  2. Uninstall the app directly; the system will erase all private app storage data completely with no leftover files.

9. Privacy Policy Updates

We may revise this policy based on product feature iterations and legal regulatory requirements. Updated versions will be published on the web disclosure page and displayed inside the app. Material changes to data handling rules will be notified via in-app pop-ups for users to review.
